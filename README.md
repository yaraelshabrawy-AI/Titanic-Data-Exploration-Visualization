# Titanic-Data-Exploration-Visualization
Titanic Data Exploration & Visualization

Project Overview

This project focuses on exploring and analyzing the Titanic dataset using Python. It demonstrates essential data analysis techniques, including data inspection, data cleaning, handling missing values, filtering, and data visualization.

Project Objectives

* Explore and understand the Titanic dataset.
* Inspect data structure and statistical information.
* Handle missing values.
* Remove duplicate records.
* Filter passengers based on passenger class.
* Visualize the relationship between passenger age and ticket fare.

Technologies & Libraries

* Python
* Pandas – Data manipulation and analysis.
* Matplotlib – Data visualization.
* Seaborn – Statistical data visualization.

Dataset

The project uses the Titanic dataset, which contains information about passengers, including:

* Passenger Class
* Age
* Gender
* Ticket Fare
* Survival Status
* Embarkation Point

Dataset Source: Titanic Dataset

Data Cleaning & Preprocessing

The following operations were performed:

1. Loaded the dataset using Pandas.
2. Inspected the dataset using info() and describe().
3. Filled missing values in the Age column using the median.
4. Filled missing values in the Embarked column using the mode.
5. Removed duplicate records.

Data Analysis & Visualization

* Filtered passengers travelling in First Class.
* Created a scatter plot to visualize the relationship between passenger age and ticket fare.

Installation & Usage

Install the required libraries:

pip install pandas matplotlib seaborn

Run the Python script:

python titanic_analysis.py

An internet connection is required to load the dataset from its online source.
